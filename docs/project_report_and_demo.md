ParkPulse — DBMS Mini Project Report & 5-Minute Viva Demo Script1. Executive SummaryParkPulse is a full-stack Smart Parking Reservation and Analytics System built on MySQL 8.4 LTS, Node.js + Express (TypeScript) with raw parameterized SQL (mysql2/promise), Next.js 14 (App Router) in a custom Warm Editorial Sand design system, Recharts, Leaflet + OpenStreetMap, and Docker Compose.2. Database Architecture Highlights14 Tables in 3NF: users, vehicles, parking_lots, parking_slots, pricing_rules, peak_multipliers, reservation_series, reservations, payments, reviews, favorite_lots, waitlist, notifications, audit_log.5 Triggers: trg_resv_before_insert, trg_resv_before_update, trg_resv_after_insert, trg_resv_after_update, trg_pricing_after_update.5 Stored Procedures & 1 Stored Function: book_slot (with SELECT ... FOR UPDATE), cancel_booking, check_in, checkout_and_bill (with ceiling-hour overstay penalty), expire_stale_reservations, and get_dynamic_price.4 Analytical Views & 1 Scheduled Event: v_daily_revenue, v_lot_occupancy, v_active_reservations, v_peak_hours, and ev_expire_stale_reservations (runs every 1 minute).Least-Privilege Security: Separate parkpulse_admin and parkpulse_app (DML + EXECUTE only; no DROP/ALTER) MySQL accounts.3. 5-Minute Viva Demonstration ScriptDatabase & Concurrency Proof (1 min):Run docker compose exec mysql mysql -uroot -pparkpulse_dev --batch -e "source /tests/verify_logic.sql" (52 passed, 0 failed).Run docker compose exec mysql bash -c "tr -d '\r' < /tests/test_concurrency.sh | bash" (J01–J04 PASS), demonstrating two concurrent sessions racing for Slot 3 where SELECT ...
